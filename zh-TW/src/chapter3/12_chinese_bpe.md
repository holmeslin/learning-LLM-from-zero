# 中文語料的 BPE 示範

## 本集目標

用一段《論語》看 byte 級 BPE 怎麼處理中文：先學出半個字、再學出整個字、最後學出詞。

## 正文

### 語料

《論語‧學而》前幾章，公版古文，直接寫在程式裡：

```python
from llmz.tokenizer import pretokenize

lunyu = """子曰：「學而時習之，不亦說乎？有朋自遠方來，不亦樂乎？人不知而不慍，不亦君子乎？」
有子曰：「其為人也孝弟，而好犯上者，鮮矣；不好犯上，而好作亂者，未之有也。君子務本，本立而道生。孝弟也者，其為仁之本與！」
子曰：「巧言令色，鮮矣仁！」
曾子曰：「吾日三省吾身：為人謀而不忠乎？與朋友交而不信乎？傳不習乎？」
子曰：「道千乘之國，敬事而信，節用而愛人，使民以時。」
子曰：「弟子入則孝，出則弟，謹而信，汎愛眾，而親仁。行有餘力，則以學文。」
子夏曰：「賢賢易色，事父母能竭其力，事君能致其身，與朋友交言而有信。雖曰未學，吾必謂之學矣。」
子曰：「君子不重則不威，學則不固。主忠信，無友不如己者，過則勿憚改。」
"""
print(len(lunyu), len(lunyu.encode("utf-8")))
print(pretokenize(lunyu)[:4])
```

執行結果：

```text
305 899
[b'\xe5\xad\x90\xe6\x9b\xb0', b'\xef\xbc\x9a\xe3\x80\x8c', b'\xe5\xad\xb8\xe8\x80\x8c\xe6\x99\x82\xe7\xbf\x92\xe4\xb9\x8b', b'\xef\xbc\x8c']
```

305 個字元、899 個 byte，每個中文字 3 個 byte。pre-tokenization 把「子曰」「：「」「學而時習之」「，」各切成一段：標點是一段，連續的中文字是一段，因為第 4 集的 regex 沒有空白可以分詞。

### 前幾次合併是半個字

```python
from llmz.tokenizer import Tokenizer, train_bpe_naive

lunyu = """子曰：「學而時習之，不亦說乎？有朋自遠方來，不亦樂乎？人不知而不慍，不亦君子乎？」
有子曰：「其為人也孝弟，而好犯上者，鮮矣；不好犯上，而好作亂者，未之有也。君子務本，本立而道生。孝弟也者，其為仁之本與！」
子曰：「巧言令色，鮮矣仁！」
曾子曰：「吾日三省吾身：為人謀而不忠乎？與朋友交而不信乎？傳不習乎？」
子曰：「道千乘之國，敬事而信，節用而愛人，使民以時。」
子曰：「弟子入則孝，出則弟，謹而信，汎愛眾，而親仁。行有餘力，則以學文。」
子夏曰：「賢賢易色，事父母能竭其力，事君能致其身，與朋友交言而有信。雖曰未學，吾必謂之學矣。」
子曰：「君子不重則不威，學則不固。主忠信，無友不如己者，過則勿憚改。」
"""
vocab, merges = train_bpe_naive(lunyu, 300, [])
for a, b in merges[:8]:
    print((a, b), (a + b).decode("utf-8", errors="replace"))
tok = Tokenizer(vocab, merges, [])
ids = tok.encode("子曰：「學而時習之」")
print(ids)
print([tok.vocab[i].decode("utf-8", errors="replace") for i in ids])
```

執行結果：

```text
(b'\xef\xbc', b'\x8c') ，
(b'\xe3', b'\x80') �
(b'\xe5', b'\xad') �
(b'\xe4', b'\xb8') �
(b'\xe8', b'\x80') �
(b'\xe4', b'\xb9') �
(b'\xe6', b'\x9c') �
[275, 273, 283, 266, 230, 153, 130, 231, 191, 146, 285, 274]
['子曰', '：「', '學', '而', '�', '�', '�', '�', '�', '�', '之', '」']
```

第一次合併是 `\xef` + `\xbc`：全形標點（，：？）的前兩個 byte，因為標點最多。第二次把第三個 byte 補上，變成完整的「，」。接下來一連串都是常見字的前兩個 byte（`\xe5\xad` 是「子」「學」「孝」的開頭），三個 byte 合完才是整個字。

44 次合併之後，encode「子曰：「學而時習之」」：「子曰」和「：「」已經各是一個 token（語料裡出現最多），「學」「而」「之」是整個字，「時習」兩個字還沒學完，各留成 3 個單 byte 的 token，印出來是 `�`。

### 中文需要更大的詞彙表

英文一個常見字 3～8 個 byte，中文一個字就 3 個 byte、一個詞 6 個以上。同樣是 10000 的詞彙表，中文能裝的「詞」比英文少很多；中文模型的詞彙表通常開到幾萬到十幾萬。另外，本書的 pre-tokenization 規則是照英文設計的，一整句中文會變成一個超長的 pre-token，BPE 要花很多次合併才能學出詞的邊界。做中文 tokenizer 時這兩點都要重新考慮。

## 重點整理

- byte 級 BPE 對中文一樣能用：先學出常見字的前 2 個 byte，再補成整個字，再黏成詞。
- 沒學完的字會留成單 byte 的 token，decode 單獨一個會是 `�`，接起來就正常。
- 中文每個字 3 個 byte，同樣大小的詞彙表裝的詞比英文少；GPT-2 的 regex 不會替中文分詞。

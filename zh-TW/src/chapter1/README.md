# 張量與剛好夠用的數學

這一章我們把工具裝好，然後認識 PyTorch 最核心的東西：張量（tensor）。LLM 從頭到尾都在對張量做加、乘、取 exp、算 log，所以我們先把形狀、索引、broadcasting、矩陣乘法練熟，再補上後面會一直用到的數學：導數、梯度、softmax、機率與 cross-entropy。

數學的部分只講會用到的，而且每個公式旁邊都有幾行程式碼可以跑。讀完這章，你就能看懂一個語言模型「輸出一排分數、轉成機率、算出 loss」的整條路。

這一章是 CS336 預設學生已經會的前置知識；CS336 本身從 Lecture 2 的 PyTorch 與資源估算開始講起，想對照可以看 <https://cs336.stanford.edu>。

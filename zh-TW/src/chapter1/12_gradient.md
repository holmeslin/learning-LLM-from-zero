# 梯度

## 本集目標

知道多個輸入的函數對每個輸入各有一個導數，排成向量就是梯度；並親手做幾步「往梯度反方向走」，看到函數值變小。

## 正文

### 一次動一個輸入

\\( f(x, y) = x^2 + y^2 \\) 有兩個輸入。對 x 的導數叫「對 x 的偏導數」，算法是：只動 x，y 不動。

```python
def f(x, y):
    return x ** 2 + y ** 2

x, y = 1.0, 2.0
h = 1e-6
dx = (f(x + h, y) - f(x, y)) / h
dy = (f(x, y + h) - f(x, y)) / h
print(round(dx, 3), round(dy, 3))
```

執行結果：

```text
2.0 4.0
```

對 x 的偏導數是 \\( 2x = 2 \\)，對 y 的是 \\( 2y = 4 \\)。把它們排成一個向量 \\( (2, 4) \\)，就是 f 在 \\( (1, 2) \\) 這一點的**梯度**（gradient）。有幾個輸入，梯度就有幾個數字。

### 用張量寫一次

模型有幾百萬個參數，當然不會一個一個寫變數。把所有輸入放進一個張量 `w`，梯度就是跟 `w` 同形狀的另一個張量：

```python
import torch

def f(w):
    return (w ** 2).sum()

def numeric_grad(f, w, h=1e-6):
    grad = torch.zeros_like(w)
    for i in range(len(w)):
        w_plus = w.clone()
        w_plus[i] += h
        grad[i] = (f(w_plus) - f(w)) / h
    return grad

w = torch.tensor([1.0, 2.0, -3.0], dtype=torch.float64)
print(numeric_grad(f, w))
```

執行結果：

```text
tensor([ 2.0000,  4.0000, -6.0000], dtype=torch.float64)
```

`torch.zeros_like(w)` 做一個和 `w` 同形狀、全 0 的張量；`w.clone()` 複製一份，才不會動到原本的 `w`。迴圈每次只把第 i 個元素推 h，算出第 i 個偏導數。結果是 \\( 2w \\)，和手算一致。這裡用 `dtype=torch.float64`（雙精度）讓差分夠準。

模型有一百萬個參數，這個迴圈就要跑一百萬次 `f`，所以實際上沒人這樣算梯度。第 2 章的 autograd 用鏈鎖律一次算出全部，只要一次反向傳播。

### 往梯度的反方向走

梯度有個重要性質：它指向函數值**上升最快**的方向。所以反過來，往梯度的反方向走一小步，函數值就會下降：

```python
import torch

def f(w):
    return (w ** 2).sum()

w = torch.tensor([1.0, 2.0, -3.0], dtype=torch.float64)
lr = 0.1
for step in range(5):
    grad = 2 * w
    w = w - lr * grad
    print(step, round(f(w).item(), 4))
```

執行結果：

```text
0 8.96
1 5.7344
2 3.67
3 2.3488
4 1.5032
```

每一步做兩件事：算出目前位置的梯度 `2 * w`（上一段已經驗證過這個公式），然後 `w = w - lr * grad`。`lr` 是**學習率**（learning rate），決定每步走多遠；0.1 代表只走梯度長度的十分之一。f 從 14 一路降到 1.5，繼續走會越來越接近最低點 0。

這五行就是**梯度下降**。訓練 LLM 時，`w` 是幾億個參數，`f` 是 loss，其他完全一樣。第 2 章我們會把 `grad = 2 * w` 換成 autograd 自動算出來的梯度，第 5 章再把 `lr` 換成會隨時間變化的排程。

### 學習率太大會怎樣

把 `lr` 改成 1.1 試試看：梯度反方向走太遠，會衝過頭到另一邊，而且越衝越遠，f 反而變大。學習率是訓練裡最重要的超參數之一，第 6 章會專門做實驗。

## 重點整理

- 多個輸入的函數，對每個輸入各有一個偏導數（只動它、其他不動）；全部排成向量就是梯度，形狀和參數一樣。
- 梯度指向上升最快的方向；`w = w - lr * grad` 往反方向走一小步，函數值會下降，這就是梯度下降。
- `lr` 是學習率，決定每步走多遠；太大會衝過頭。
- 有限差分要對每個參數各算一次，太慢；第 2 章用 autograd 一次算完。

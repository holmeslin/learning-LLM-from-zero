# 導數與鏈鎖律

## 本集目標

用「輸入動一點點，輸出動多少」理解導數，會用有限差分算出來，並理解鏈鎖律：函數套函數的導數，就是每一層的導數相乘。

## 正文

### 導數是什麼

有一個函數 \\( f(x) = x^2 \\)。在 \\( x = 3 \\) 的地方，把 x 往右推一點點，f 會變多少？

```python
def f(x):
    return x ** 2

x = 3.0
h = 0.001
print(f(x))
print(f(x + h))
print((f(x + h) - f(x)) / h)
```

執行結果：

```text
9.0
9.006001
6.000999999999479
```

x 動了 0.001，f 動了 0.006001，比值大約是 6。這個比值就是導數：**輸入動一點點，輸出動幾倍**。h 越小，比值越接近正確答案 \\( 2x = 6 \\)。

這種「真的去動一點點再除回來」的算法叫有限差分。它慢又不精確，但很直觀，拿來驗算非常好用。第 2 章的 autograd 會幫我們精確地算，但背後的意思就是這個。

這一集和下一集用 Python 的浮點數而不是張量，因為 PyTorch 預設的 `float32` 太粗，差分會不準。

### 為什麼 LLM 需要導數

訓練模型時有一個數字叫 loss，代表模型猜得有多差；loss 是模型所有參數的函數。如果知道「某個參數往上動一點，loss 會變大還是變小、變多少」，我們就知道該把那個參數往哪邊調。導數就是這個「變多少」。第 2 章會用它寫出梯度下降。

### 鏈鎖律：函數套函數

神經網路是幾十層函數套在一起。\\( g(x) = (2x + 1)^2 \\) 就是兩層：先算 \\( u = 2x + 1 \\)，再算 \\( u^2 \\)。它對 x 的導數怎麼算？

```python
def inner(x):
    return 2 * x + 1

def outer(u):
    return u ** 2

def g(x):
    return outer(inner(x))

x = 1.0
h = 1e-6
numeric = (g(x + h) - g(x)) / h

u = inner(x)
d_outer = (outer(u + h) - outer(u)) / h
d_inner = (inner(x + h) - inner(x)) / h

print(round(numeric, 3))
print(round(d_outer, 3), round(d_inner, 3))
print(round(d_outer * d_inner, 3))
```

執行結果：

```text
12.0
6.0 2.0
12.0
```

直接對 `g` 做差分得到 12。分開算：外層 `outer` 在 \\( u = 3 \\) 的導數是 6，內層 `inner` 的導數是 2，相乘也是 12。這就是**鏈鎖律**：

\\[ \frac{dg}{dx} = \frac{dg}{du} \cdot \frac{du}{dx} \\]

白話：x 動一點，u 動 2 倍；u 動一點，g 動 6 倍；所以 x 動一點，g 動 \\( 2 \times 6 = 12 \\) 倍。

不管套幾層都一樣：整體的導數等於每一層導數相乘。神經網路訓練時從最後一層往回一層一層乘，這個過程叫反向傳播（backpropagation），第 2 章的 `backward()` 就是它。這裡用 `round` 把結果四捨五入到小數第三位，是為了把差分的雜訊去掉。

### 會用到的幾個導數

| 函數 | 導數 |
| --- | --- |
| \\( x^2 \\) | \\( 2x \\) |
| \\( ax \\) | \\( a \\) |
| \\( e^x \\) | \\( e^x \\) |
| \\( \ln x \\) | \\( 1/x \\) |

後面講 softmax 和 cross-entropy 時會碰到 \\( e^x \\) 與 \\( \ln x \\)，記得它們的導數長這樣就夠了，不用背更多。

## 重點整理

- 導數是「輸入動一點點，輸出動幾倍」；用 `(f(x + h) - f(x)) / h` 可以估算。
- loss 對參數的導數告訴我們參數該往哪邊調，這是訓練的核心。
- 鏈鎖律：函數套函數的導數等於每一層導數相乘；反向傳播就是從外層往內層一路乘回去。

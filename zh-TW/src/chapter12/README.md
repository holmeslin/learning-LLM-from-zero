# 評估

前兩部我們一直用 loss 與 perplexity 判斷模型好不好。可是模型最後要拿來做事：回答問題、接著故事寫下去、照指令行動。一個 perplexity 比較低的模型，不見得比較會做這些事。

這一章先看 perplexity 能比較什麼、不能比較什麼。接著認識 benchmark 與 few-shot，並自己寫出多選題的評分：對每個選項算 log 機率，挑最大的。我們用一份原創、TinyStories 風格的小題庫，量第 5 章訓練好的模型。再來是沒有固定選項的生成式題目，怎麼用規則評分、怎麼請另一個模型當評審，以及它們各自的偏誤。最後一集檢查 benchmark 的題目有沒有早就出現在訓練資料裡，也就是資料污染。

這一章的程式在 `src/llmz/evaluation.py`，對應 CS336 評估的講次，見 <https://cs336.stanford.edu>。

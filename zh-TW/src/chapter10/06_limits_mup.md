# 限制與 μP 一瞥

## 本集目標

知道 scaling law 的結論在哪些地方會失準：擬合方式、實驗設定、訓練以外的成本；並認識讓學習率等超參數能從小模型搬到大模型的 μP。

## 正文

### 同一份資料，不同的擬合

第 2 集的 Chinchilla 公式來自原論文的第三種方法。2024 年 Epoch AI 的 Besiroglu 等人從論文的圖重建資料、重新擬合同一個公式，得到 \\( E = 1.8172 \\)、\\( A = 482.01 \\)、\\( B = 2085.43 \\)、\\( \alpha = 0.3478 \\)、\\( \beta = 0.3658 \\)，並指出原本的擬合和資料對不太上。兩組參數對同一個預算給出的建議差多少？

```python
import numpy as np

from llmz.scaling import chinchilla_loss

fits = {
    "Hoffmann 等人（2022）": dict(e=1.69, a=406.4, b=410.7, alpha=0.34, beta=0.28),
    "Besiroglu 等人（2024）": dict(e=1.8172, a=482.01, b=2085.43, alpha=0.3478, beta=0.3658),
}
grid = np.logspace(8, 13, 5000)
for c in [1e21, 1e24]:
    for name, params in fits.items():
        loss = chinchilla_loss(grid, c / (6 * grid), **params)
        n = grid[np.argmin(loss)]
        d = c / (6 * n)
        print(f"C = {c:.0e}  {name}：N = {n:.2e}，每個參數 {d / n:3.0f} 個 token")
```

執行結果：

```text
C = 1e+21  Hoffmann 等人（2022）：N = 1.82e+09，每個參數  50 個 token
C = 1e+21  Besiroglu 等人（2024）：N = 2.78e+09，每個參數  22 個 token
C = 1e+24  Hoffmann 等人（2022）：N = 4.13e+10，每個參數  98 個 token
C = 1e+24  Besiroglu 等人（2024）：N = 9.59e+10，每個參數  18 個 token
```

`**params` 把字典展開成關鍵字參數（`e=1.69, a=406.4, ...`）。重新擬合的版本在兩個預算下都給出每個參數 20 個上下的 token（22 與 18），和原論文的另外兩種方法一致；原版的公式則隨預算增加越來越偏向多資料。同樣的實驗資料，擬合方式不同，外推到 \\( 10^{24} \\) 時建議的模型大小差了一倍多。

### 實驗設定會改變結論

- **學習率排程**：第 2 集說過，Kaplan 與 Chinchilla 結論不同，一部分是因為排程沒配合訓練長度。
- **超參數**：每個大小用同一個學習率，對某些大小會不公平。下一節的 μP 就是為了這個問題。
- **資料**：指數與常數都和資料有關。在 TinyStories 這種簡單的資料上擬合出來的數字，不能拿去預測網頁資料。
- **重複資料**：公式假設每個 token 都是新的。資料不夠、要重複看好幾輪時，效果會變差。
- **架構與 tokenizer**：換了架構或詞彙表，loss 的尺度就變了，要重新擬合。

### 訓練不是唯一的成本

Chinchilla 最佳只考慮訓練的計算量。但模型訓練完要服務很多使用者，**推論**的成本跟模型大小成正比（第 11 章）。如果一個模型會被用很久，寧可訓練一個比 Chinchilla 最佳更小的模型、讓它看遠多於 20 倍參數量的資料：訓練多花一點，之後每次推論都省。例如 Meta 的 Llama 3 8B 用了超過 15 兆個 token 訓練，每個參數將近 2000 個 token。這種刻意「過度訓練」小模型的做法現在很普遍。

### μP：讓超參數可以搬家

做 scaling law 要訓練很多大小不同的模型，每個都要好的學習率。第 6 章第 9 集掃描學習率花了不少時間，模型一大，掃描的成本就付不起。理想狀況是：在小模型上調好的學習率，直接用在大模型上也是最好的。

可惜第 4 章那種標準的初始化與學習率（叫 standard parametrization）做不到這件事：模型變寬時，每一層輸出的大小與每一步的更新幅度會隨寬度改變，最好的學習率也跟著移動，通常是越寬越小。

**μP**（Maximal Update Parametrization，Yang 等人，2022）依每一層的寬度調整初始化的大小、學習率的大小與輸出的縮放，讓模型變寬時每一層更新的幅度維持不變。這樣在小模型上找到的最佳學習率，可以直接**搬到**（transfer）大模型上。許多大模型的訓練都用了 μP 或類似的做法來決定超參數。

本書沒有實作 μP。上一集的迷你 scaling law 對所有大小都用同一個學習率 3e-3，這是它的一個限制。

## 重點整理

- 同一份資料、不同的擬合方式，外推的建議可以差一倍以上；Besiroglu 等人重新擬合後，每個參數約 20 個 token。
- 學習率排程、超參數、資料、重複資料、架構都會改變擬合出來的數字。
- Chinchilla 最佳只看訓練成本；考慮推論，常會刻意用更多資料訓練更小的模型。
- μP 依寬度調整初始化與學習率，讓小模型上調好的超參數能直接用在大模型。

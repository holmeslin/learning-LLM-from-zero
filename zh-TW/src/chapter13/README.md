# 資料：從網頁到訓練集

第 5 章的模型讀的是 TinyStories：別人整理好、乾乾淨淨的兒童故事。可是大型語言模型的訓練資料，大宗來自網路上的網頁，而網頁原本又亂又重複，裡面有選單、廣告、各種語言、電話號碼與 email，還有一模一樣的頁面出現幾千次。模型學到什麼，很大一部分取決於這些資料怎麼篩。

這一章從 Common Crawl 的原始檔案開始，一步一步做出一條資料管線：先讀 WARC、把 HTML 轉成文字；接著辨識語言、遮蔽個資、了解有害內容分類器的角色；再用 Gopher 的品質規則與自己訓練的品質分類器篩掉低品質的文字；然後做逐行的 exact dedup，以及用 MinHash 與 LSH 找近似重複的文件。最後把這些步驟接起來，量出每一步留下多少文件，輸出成第 3 章格式的 token 檔，並談資料混合與合成資料。

我們只下載一個 WARC 檔的前 32 MiB，所有東西都在一台筆電上跑得完。網頁內容不進 repo，書裡也只放統計數字，不貼網頁的文字。

這一章的程式在 `src/llmz/pipeline.py`，對應 CS336 資料的講次與 Assignment 4，見 <https://cs336.stanford.edu>。

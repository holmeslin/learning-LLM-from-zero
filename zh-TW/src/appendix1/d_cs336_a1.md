# 對照 CS336 A1 測試清單

## 本集目標

如果你同時在看 Stanford CS336 的 Assignment 1，這張表告訴你每個作業項目對應本書哪一集、`llmz` 裡哪個東西、哪個測試在驗證它。本書的程式碼與測試都是原創，不能直接拿去交作業，但做完本書再做 A1 會很順。

幾個本書刻意不同的地方：

- A1 的函式介面（例如把權重當引數傳進去的 adapter）是為了自動評分設計的；本書直接用 `nn.Module`。
- A1 要求 BPE 在 TinyStories 全量上訓練；本書只用前 160 MiB 的標準語料，數字會不同。
- A1 的 RoPE、attention 等測試有它自己的固定輸入與預期輸出；本書的測試改用 PyTorch 內建函式與數學性質驗證。
